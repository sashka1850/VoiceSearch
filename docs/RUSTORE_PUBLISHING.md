# Публикация VoiceSearch в RuStore

Документ-чек-лист: что нужно подготовить и где это взять, чтобы загрузить
билд в RuStore Developer Console.

> Все шаги — за один присест ~30–45 минут (без учёта рисования иконки и
> скриншотов). Дальше — модерация RuStore, обычно 1–3 рабочих дня.

## 0. Аккаунт разработчика

1. https://console.rustore.ru — регистрация через ВКонтакте / e-mail.
2. Подтверждение личности — паспортные данные либо ИНН/ОГРН для юрлица.
   Без подтверждения нельзя публиковать платные приложения; для
   бесплатного VoiceSearch достаточно базового аккаунта.
3. Согласие с офертой разработчика.

## 1. Готовый AAB

```bash
./gradlew :app:bundleRelease
```

Результат: `app/build/outputs/bundle/release/app-release.aab`.

**Проверьте перед загрузкой:**

- `versionCode` инкрементнут относительно предыдущего релиза
  (см. `app/build.gradle.kts`)
- `versionName` человекочитаем — например `0.1.0`
- AAB подписан **релизным ключом** (см. README → "Релизная сборка"),
  не debug-keystore. Иначе RuStore отвергнет билд при загрузке.
- Размер APK после R8 — ожидаемо ~3 MB.

## 2. Метаданные приложения

### Название
`VoiceSearch` (или ваш ребрендинг)

### Краткое описание (до 80 символов)
> Голосовой поиск по таблицам XLSX/CSV с отметкой строк и синхронизацией с Я.Диском

### Полное описание (до 4000 символов)
Можно скопировать из `README.md` раздел "Возможности" + чуть расширить.
Пример первого абзаца:

> VoiceSearch — приложение для быстрого поиска значений в таблицах Excel
> и CSV голосом. Открываете таблицу с локального файла или ссылки на
> Яндекс.Диск, нажимаете и удерживаете кнопку микрофона, произносите
> искомое значение — приложение находит совпадение, подсвечивает строку
> и предлагает поставить отметку. Результат можно отправить обратно в
> исходный файл на Яндекс.Диске или поделиться через любой мессенджер.

### Категория
`Бизнес` или `Производительность`. RuStore не различает их строго —
оба подходят.

### Возрастной рейтинг
`0+` — приложение не содержит контента для взрослых, рекламы,
встроенных покупок.

### Контактная почта
Та, что указана в Privacy Policy — `<ваш email>`.

## 3. Графика

| Что | Размер | Где взять |
|---|---|---|
| Иконка приложения | 512×512 PNG, без альфы | `app/src/main/res/mipmap-*/ic_launcher` (после Stage 8) |

| Скриншоты | 1080×1920 (минимум 2, желательно 5–8) PNG/JPG | Снимаются с эмулятора Pixel 5 |

**Идеи скриншотов:**
1. Главный экран с открытой таблицей + кнопка микрофона
2. Найденное совпадение, диалог отметки
3. Экран импорта (выбор файл vs Я.Диск)
4. Настройки таблицы (выбор колонки поиска)
5. Список таблиц с табличным фоном
6. Тёмная тема главного экрана

## 4. Privacy Policy URL

RuStore требует **публичный URL** на политику конфиденциальности.
Самое простое:

```
https://github.com/sashka1850/VoiceSearch/blob/master/PRIVACY_POLICY.md
```

GitHub отдаёт `.md` как HTML — этого RuStore достаточно. Если хочется
красивее — включите GitHub Pages для репозитория и используйте URL
`https://sashka1850.github.io/VoiceSearch/PRIVACY_POLICY.html`.

## 5. Разрешения и обоснования

При загрузке AAB RuStore попросит обосновать каждое чувствительное
разрешение. Текущие у нас:

| Разрешение | Обоснование для модератора |
|---|---|
| `RECORD_AUDIO` | "Используется при удержании кнопки микрофона для голосового ввода поискового запроса. Запись передаётся в системный сервис распознавания речи Android. Файлы записи не сохраняются." |
| `INTERNET` | "Используется только для опциональной синхронизации с Яндекс.Диском по явному действию пользователя. Без авторизации в Я.Диске сетевые запросы не выполняются." |

## 6. Чек-лист "Не получим отказ"

- [ ] Приложение запускается на чистом эмуляторе Android 7.0 (API 24, наш minSdk)
- [ ] Иконка не нарушает чужих ТЗ (не реиспользуем логотип Яндекса как иконку приложения)
- [ ] В описании нет упоминаний "Google Play" — это про другой стор
- [ ] Privacy Policy URL открывается без авторизации в браузере инкогнито
- [ ] Скриншоты сделаны в текущей версии (не от предыдущего MVP)
- [ ] `versionCode` строго больше предыдущего опубликованного
- [ ] AAB подписан релизным ключом (см. вывод `apksigner verify --print-certs app-release.apk`)

## 7. После публикации

- Сохраните `voicesearch-release.jks` и `keystore.properties` в **двух**
  независимых местах (например менеджер паролей + зашифрованный архив
  на Яндекс.Диске). Потеря ключа = невозможность выпустить обновление,
  пользователи RuStore остаются на последней опубликованной версии
  навсегда.
- Не коммитьте `.jks` и `keystore.properties` в git — они уже в `.gitignore`.
- Для следующего релиза: инкрементните `versionCode` и `versionName`,
  пересоберите AAB, загрузите в RuStore Console → "Загрузить новую версию".
